# RyanLGriffith.com

**Programmer | Engineer | Artist**

The personal portfolio website of **Ryan L. Griffith** — a showcase of programming projects, engineering builds, digital art, and interactive demos, backed by a dynamic, filterable portfolio system.

🔗 Live site: [ryanlgriffith.com](https://ryanlgriffith.com)

---

## 📖 About

RyanLGriffith.com is a personal site built to document and present a wide range of creative and technical work — spanning software development, embedded electronics, mechanical design, and visual art. The site reflects an interdisciplinary approach: an engineer's rigor applied to creative work, and a designer's eye applied to technical problems.

> *"Ryan is a driven, intellectually curious person who approaches the world with a maker's instinct and a scientist's need to understand not just what is true, but why and how we know."*

---

## ✨ Site Features

- **Dynamic Portfolio Browser** (`portfolio.php`) — a database-backed project gallery with:
  - **Sorting**: Recent, Oldest, A–Z, Z–A
  - **Category filters**: Show All, Featured, Programming, Art, Engineering
  - Thumbnail previews with title, category tags, and short descriptions for each entry
- **Certifications Gallery** — a dedicated section displaying earned professional certifications with images and dates earned
- **Demos Page** — interactive, embedded playable demos (Pico-8 titles) that visitors can try directly in-browser
- **About Page** — bio and headshot introducing Ryan and his working philosophy
- **Responsive Navigation** — collapsible hamburger menu (`☰`) and mobile-friendly viewport for use across devices
- **Consistent Branding** — custom logo and site identity used across all pages
- **Versioned Site History** — the site itself is a tracked portfolio project, with past major versions (V3, V4) documented as entries in the portfolio

### 🧱 Tech Stack (observed)
- **PHP** — powers the dynamic portfolio page and filtering/sorting logic
- **HTML/CSS/JS** — front-end structure, styling, and interactivity
- **Database-backed content** — portfolio entries pulled dynamically rather than hardcoded (introduced in Website V3)
